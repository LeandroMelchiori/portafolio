Casos de estudio privados

Automatizaciones que reemplazan tareas manuales y sostienen operaciones completas.

El código no es público porque estas soluciones trabajan con procesos internos y datos sensibles. Por eso, cada caso se presenta desde el problema que resuelve, el sistema construido y su impacto operativo.

Datos · Estadística · Privacidad Caso privado

Observatorio de Datos Banco Solidario

Convierte planillas dispersas de gestión territorial en una base confiable y en reportes estadísticos automáticos para comprender el alcance, las características y las necesidades de los emprendimientos acompañados.

Problema

La información llegaba en múltiples Excel y documentos Word, con formatos diferentes, categorías escritas de distintas maneras, registros duplicados y datos que requerían revisión manual antes de producir cualquier informe.

Solución

La aplicación importa varios archivos, normaliza rubros, edades, antigüedad, formalización y capacitaciones, consolida los registros, detecta inconsistencias y conserva la trazabilidad del archivo y la hoja de origen.

Impacto

Calcula automáticamente indicadores, distribuciones, comparaciones, tablas y gráficos; permite filtrar resultados y exportar reportes en Excel, CSV y PNG sin enviar documentos sensibles a un servidor.

Next.js · React · TypeScript · SheetJS · Mammoth · IndexedDB · Vitest

Automatización documental · Gestión de asistentes Caso privado

Gestión Integral de Talleres y Certificaciones

Centraliza el recorrido completo de una actividad formativa: registro de asistentes, validación de datos, generación personalizada de certificados, historial y envío automatizado de comunicaciones.

Problema

Crear certificados uno por uno, mantener listados de participantes, corregir nombres o correos y enviar mensajes personalizados implicaba repetir tareas, alternar entre planillas y documentos, y asumir un alto riesgo de errores u omisiones.

Solución

El sistema carga participantes desde Excel, Word o PDF, detecta duplicados y columnas incorrectas, mantiene una base de asistentes, genera certificados desde plantillas configurables y permite incorporar folios y códigos QR.

Impacto

Automatiza correos mediante plantillas personalizadas y Gmail OAuth, administra colas, pausas, reintentos, rebotes, correcciones y reenvíos. Un proceso manual fragmentado pasa a ser guiado, trazable y reutilizable.

Python · Tkinter · SQLite/SQLCipher · PDF · Gmail API · OAuth · QR

Backend multi-tenant · Ticketing · Operación Caso privado

Pulse — Gestión Integral de Eventos y Ticketing

Diseña la infraestructura de una plataforma para que productoras, clubes, teatros y festivales puedan administrar la operación completa de sus eventos, desde la publicación hasta el ingreso del público.

Problema

La organización de eventos suele repartir datos entre formularios, planillas, sistemas de cobro y controles de puerta, dificultando conocer el stock real, coordinar al personal y mantener trazabilidad sobre compras, entradas y devoluciones.

Solución

La API separa la información por organizador y permite gestionar espacios, eventos, tipos de entrada, preventas, staff, compradores, cortesías y comunicaciones. El checkout usa idempotencia y reservas atómicas para evitar operaciones duplicadas y sobreventa.

Impacto

Integra emisión de entradas digitales, billetera del comprador, reembolsos, recuperación de stock y check-in con permisos de puerta, además de paneles para organizadores y administración central.

Java · Spring Boot · PostgreSQL · JWT · Flyway · Testcontainers · S3 · Resend
