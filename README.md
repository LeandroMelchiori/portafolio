# Portafolio profesional — Leandro Melchiori

Sitio personal orientado a presentar experiencia, enfoque de trabajo y proyectos con aplicación real.

## Demo

- [Ver portafolio publicado](https://portafolio-leandromelchiori.vercel.app/)

## Posicionamiento

El sitio presenta un perfil Full Stack con foco en:

- backend con Java y Spring Boot;
- frontend con React, Next.js y TypeScript;
- automatización y procesamiento de datos con Python;
- aplicaciones local-first, PWA y funcionamiento offline;
- tecnología aplicada a economía social, capacitación y procesos reales.

## Proyectos destacados

- Herramientas para Emprendedores
- EcoSocial
- TaskFlow
- Analizador Banco Solidario
- Generador de Certificados
- Pulse Tickets
- Club Deportivo
- LiteraLura

## Tecnologías

**Backend:** Java, Spring Boot, Spring Security, JWT, JPA, Hibernate, Flyway, JUnit, Mockito y Testcontainers.

**Frontend:** React, Next.js, TypeScript, JavaScript, HTML, CSS, IndexedDB, PWA, Vitest y Playwright.

**Datos y automatización:** Python, SQLite, PostgreSQL, MySQL, MongoDB, Excel, procesamiento de documentos, PDF y Gmail API.

**Infraestructura:** Git, GitHub Actions, Docker, Vercel, Render, MinIO y almacenamiento compatible con S3.

## Ejecución local

No requiere proceso de compilación. Se puede abrir `index.html` directamente o levantar un servidor estático local.

```bash
python -m http.server 8000
```

Luego abrir `http://localhost:8000`.

## Decisiones principales

- Se priorizan productos y casos de estudio por encima de ejercicios académicos.
- Las tecnologías listadas están respaldadas por proyectos concretos.
- Los proyectos privados se presentan como casos de estudio sin exponer código ni información sensible.
- El contacto se realiza mediante enlaces reales, sin simular envíos de formularios.
- El año del footer se actualiza automáticamente.
- El diseño incluye navegación semántica, skip link y soporte para reducción de movimiento.
